# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:

To design and develop a Library Management System using software engineering concepts and diagrams to manage library activities such as adding books, issuing books, returning books, and maintaining student records.

# SRS (Procedure):

1.Identify the requirements of the Library Management System.

2.Study the existing library management process.

3.Identify the users, such as librarian, students, and admin.

4.Define the functional and non-functional requirements.

5.Identify the major modules, such as book management and member management.

6.Design the Use Case Diagram to represent user interactions.

7.Design the Class Diagram to represent the system structure.

8.Prepare the Sequence and Activity Diagrams to describe system operations.

9.Draw the State Chart Diagram and Data Flow Diagram to represent system behaviour and data flow.

10.Verify all six diagrams to ensure that the system requirements are properly represented.
